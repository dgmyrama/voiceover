Panduan Mode Single

  • Pilih Karakter Suara dan Tone.
  • Masukkan teks, klik Generate.
  • Gunakan Refine Text untuk hasil natural.

Saran: Proses teks per paragraf atau maksimal sekitar 2.000 karakter per kali generate. Jika gagal, coba lagi dengan jumlah karakter yang lebih sedikit.

Panduan Mode Dialog

  • Klik + Tambah Baris untuk menambah percakapan.
  • Pilih suara berbeda untuk setiap baris.
  • Isi dialog di kolom teks.
